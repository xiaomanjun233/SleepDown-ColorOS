# 首页快照归属、反色与凝光默认参数

本轮按用户最新反馈调整：壁纸下的 Dock、按钮及菜单普通字图跟随首页反色，不普遍叠加阴影；无壁纸时底色恢复原生明暗默认；多课表预览必须包含新 Dock，且实际 Dock 不能浮在管理界面上方。用户补充的直角问题发生在 shortcut 开始全屏模糊时，不能当作加号菜单本身的形变问题处理。

## 首页与快照

- 原生 Dock 移入 `screenGraphicsLayer` 的完整首页录制范围，并保持在课程专用 CompositionLocal 之外。多课表入口、快照遮罩和管理界面移到该录制层之后，作为后绘制的同级覆盖层。
- shortcut 冻结时，Dock 和加号先在完整尺寸的首页层中绘制，再随整个首页进入既有降采样模糊层；原先 Dock 位于首页缓存外，会直接进入降采样层。此修改针对两条材质渲染路径的不一致，没有强制开启原生 View 的 `clipToOutline`、替换圆角形状或添加逐帧监听。
- 保留原生 Dock 的稳定输入边界，不传入 shortcut 动画进度。旧的多课表图片缓存使用 v3；新截图使用 v4，避免继续显示缺少原生 Dock 的旧预览。只更新视觉缓存命名，不修改课表数据或备份格式。

## 颜色与反馈

- 首页原生材质明暗仍由应用主题决定；普通图标和文字单独取与首页相同的 `AdaptiveGlassState.contentColor`，避免为了反色重建原生材质、干扰 3+1 融合。
- 有壁纸时使用天气中性底色，无壁纸时不再覆盖原生控件底色。设置页仍使用原有规则。Dock 选中态及加号背景保留主题强调色，Dock 跟手光始终使用同一强调色；加号图标也跟随首页反色。
- 移除上一版无条件开启的 Dock 文字及图标阴影。右上角原生菜单的文字、图标接入同一反色；普通模式保留既有 Compose 菜单，仅同步其前景色。
- 原生弹出菜单跟手光由 2× 提至 3×。倍率基于系统初始强度范围计算，材质刷新不会逐次累乘；其他按钮仍为 2×，跟手光颜色保持原生默认。

## 课程凝光

- 凝光不再读取旧的轮廓光开关、卡片透明度、壁纸亮度衰减或课程模糊滑杆；渐变课程色始终参与绘制。
- 取消凝光模式下的旧轮廓光开关及模糊滑杆，只保留着色强度，默认和吸附值为 50%。显式保存过的着色值仍保留；普通质感模式的原参数与开关不受影响。
- 使用 COUI 内容通透材质 `TYPE_CONTENT_TRANSPARENT_BUTTON` 的默认模糊与颜色滤层，轮廓沿用原生 `TYPE_CONTENT_CAPSULE_1`，跟手光恢复该课程表面的系统默认强度。COUI 没有专用的课程卡片预设；这些是现有内容材质预设，并非新增系统课程卡组件。
- 唯一应用额外绘制是课程配色的渐变，不再叠加旧白边、黑白明暗或额外轮廓参数。
